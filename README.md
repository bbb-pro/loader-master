# 装柜大师 (Loader Master)

> 单文件、零依赖的集装箱装柜（装箱）计算工具 —— 在浏览器里一键算出「怎么码、能装多少、重心稳不稳」，并导出 PDF 作业单。

装柜大师是一个纯前端的集装箱装载规划工具，无需后端、无需安装，双击 HTML 即可在任意现代浏览器运行。它适用于外贸、仓储、物流、拼柜等场景，帮助你在发货前快速得到一份可落地的装柜方案。

- 🌐 在线使用：https://bbb-pro.github.io/loader-master/
- 📦 单文件交付：`装柜大师.html`（约 70 KB，内嵌 Three.js / SheetJS / jsPDF 全部依赖）

---

## ✨ 功能特性

| 类别 | 说明 |
| --- | --- |
| **多柜型支持** | 内置 20GP / 40GP / 40HQ / 45HQ 四种标准集装箱内尺寸与限重 |
| **砖砌码盘算法** | 同形矩形托盘采用「砖砌式交错」布局，密度贴合人工摆放（如 1200×1000 托盘在 40HQ 可达 22 托/层） |
| **打托方案预览** | 勾选托盘后实时生成俯视打托图（SVG），直观核对每托能放几箱、如何交错 |
| **3D 可视化** | Three.js 渲染装柜结果，可旋转 / 缩放 / 平移查看；点击任意箱子可旋转朝向或删除 |
| **摆放顺序** | 支持「从里到外」（柜里端优先再向上）与「从外到里」（柜门端优先）两种策略 |
| **优先级调度** | 1/2/3 级优先级，优先货物置于柜内最里侧底层，靠门货物最后装入 |
| **理论容量估算** | 针对当前柜型，估算单个货物最多可放数量与整托高度，辅助快速判断 |
| **Excel 互通** | 一键下载导入模板，填写后批量导入；结果可导出 Excel 明细 |
| **PDF 作业单** | 导出含汇总表、3D 示意图、货物明细、作业说明的中文 PDF，表格自适应字号避免重叠 |
| **零依赖离线** | 所有依赖通过 CDN importmap 加载，HTML 单文件即可分发，计算全程本地完成 |

## 🚀 快速开始

### 方式一：在线使用（推荐）
直接打开 **https://bbb-pro.github.io/loader-master/** 即可，无需下载。

### 方式二：本地使用
1. 下载本仓库的 `装柜大师.html`（或克隆仓库后取该文件）。
2. 双击用浏览器（Chrome / Edge / Firefox 等）打开。
3. 首次加载会从 CDN 拉取 Three.js 等依赖，请保持联网；之后可离线使用已缓存的资源。

> 注意：单文件 HTML 通过 CDN importmap 引入 Three.js，因此需要一次联网加载。若需完全离线，可自行将 Three.js 本地化后内联。

## 📖 使用说明

### 1. 选择柜型
在顶部「柜型」下拉框选择目标集装箱，默认 `40HQ`。

内置标准集装箱尺寸（尺寸单位：米；限重单位：吨；容积单位：立方米）：

| 柜型 | 外部尺寸 (长×宽×高) | 内容积 (长×宽×高) | 限重 | 容积 |
| --- | --- | --- | --- | --- |
| 20GP | 6.058 × 2.438 × 2.591 | 5.94 × 2.34 × 2.39 | 28.25 t | 33 m³ |
| 40GP | 12.192 × 2.438 × 2.591 | 12.06 × 2.34 × 2.39 | 28.8 t | 67 m³ |
| 40HQ | 12.192 × 2.438 × 2.896 | 12.06 × 2.34 × 2.69 | 30.2 t | 76 m³ |
| 45HQ | 13.58 × 2.438 × 2.896 * | 13.58 × 2.35 × 2.69 * | 27 t * | — * |

> * 45HQ（45 英尺加长高柜）暂未提供标准数据源，上表数值沿用原预设，仅供参考；20GP / 40GP / 40HQ 均采用标准集装箱公开数据。

### 2. 添加货物
点击「＋ 添加货物」新增一个货物卡片，逐项填写：

- **名称**：便于辨识（如「A 款礼盒」）。
- **长 / 宽 / 高（mm）**：单箱外尺寸。
- **单重（kg）**：单箱重量，默认 0。
- **数量**：该货物总件数（非托数）。
- **允许旋转**：勾选后算法可交换长/宽方向以提升装载密度。
- **允许倒置**：勾选后允许箱体上下翻转摆放。
- **优先级**：1（优先，置柜内最里侧底层）/ 2（默认）/ 3（靠门，最后装入）。
- **分组**：相同分组尽量集中摆放；同一托的货物建议填同一分组。
- **最大上层承重（kg）**：该箱顶面可承受的最大重量，用于堆码校验。

### 3. 托盘与打托方案
若货物以托盘为单位装载，勾选「托盘」并填写：

- **托盘长 / 托盘宽（mm）**：如 1200×1000。
- **每托数量**：每托盘码放多少箱。
- **托盘重 / 托盘高（mm）**：托盘自重与高度（默认 150 mm）。

勾选后，卡片底部实时显示 **打托方案（俯视图）**：以 SVG 画出托盘上箱子的排布与交错方式，并标注「每托 X 箱 / Y 层 / 整托高 Z mm」，方便你核对打托是否正确。

### 4. 摆放顺序与间隙
- **摆放顺序（装柜优先级）**：
  - `从里到外`：柜里端优先装满底层，再逐层向上（默认）。
  - `从外到里`：柜门端优先，便于先卸靠门货物。
- **箱间隙（mm）**：箱子之间的留缝，默认 0。实际作业需留通风/缓冲缝时填入。

### 5. 生成方案
点击「🚀 计算装柜」生成方案。结果区会显示：
- **汇总**：共需几个柜、总件数、总重、总体积、各柜装载率。
- **3D 预览**：装柜后的立体效果，可用鼠标拖拽旋转、滚轮缩放、右键平移。
- **货物明细**：每个箱子所在的柜号、坐标、尺寸、分组、托盘信息。
- **告警**：超重、超高、重心偏移等风险提示。

### 6. 3D 交互
- **旋转视角**：鼠标左键拖拽。
- **缩放**：滚轮。
- **平移**：右键拖拽。
- **选中箱子**：左键点击任意箱子，弹出浮层菜单（固定在预览框底部），可：
  - 🔄 **旋转 90°**：交换该箱长/宽朝向（若旋转后与邻居冲突会提示）。
  - 🗑 **删除**：从方案中移除该箱实例，算法自动重排。

### 7. 理论容量估算
在货物卡片输入长/宽/高并选择柜型后，卡片内会显示「当前柜型最多可放 X 件」的估算，以及整托高度，用于发货前快速判断柜容是否够用。

### 8. 导入 / 导出
- **导入**：点击「导入」下载 Excel 模板（含全部字段表头），按列填写后选择文件批量导入货物，免去逐一手填。
- **导出 Excel**：将计算结果（汇总 + 明细）导出为 `.xlsx`。
- **导出 PDF**：导出中文作业单，含汇总表、3D 示意图、货物明细、仓库作业说明。表格采用自适应字号，超长内容自动省略，避免列重叠。

## 🧠 算法简介

- **柜级砖砌码盘**：当一层内可放多个相同矩形托盘（或同形箱子）时，采用「砖砌式交错」——相邻行交替 90° 朝向，消除行列对齐造成的空隙，密度与人工贴合摆放一致（典型：40HQ + 1200×1000 托盘 = 22 托/层）。
- **托级打托**：`palletLevelLayout()` 枚举砖砌行组合，求每托每层最大箱数，供理论估算与 3D 渲染共用，保证「理论容量」与「实际渲染」严格一致。
- **由内向外推进**：从里到外时，先码第一托底层 → 隔壁交错第二托底层 → 第一托第二层 → 第二托第二层，依次向外推进，符合人工码盘习惯。
- **优先级调度**：按优先级排序后填充，优先货物置于柜里端底层，靠门货物最后装入，便于卸货顺序。

> ⚠️ 本工具为模拟估算，实际装柜请结合货物特性、捆扎方式、重心与运输要求进行现场确认。

## 🛠 技术栈

- **前端框架**：原生 HTML + Tailwind CSS（CDN）
- **3D 渲染**：Three.js（CDN importmap）
- **表格处理**：SheetJS（xlsx 导入导出）
- **PDF 生成**：jsPDF + Canvas 栅格化（规避中文字体缺失）
- **运行环境**：纯浏览器端，无后端、无构建步骤
