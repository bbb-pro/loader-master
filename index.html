关于集装箱装柜计算工具

「装柜大师」是一款免费的在线集装箱装柜计算工具，用于在出货前快速估算一个柜子到底能装多少货。 只需填写纸箱的长、宽、高和数量，选择柜型（20GP、40GP、40HQ、45HQ，或直接自定义内尺寸）与箱间隙， 工具就会自动算出理论最大装载量、占用体积、装载率，并给出每一层的实际摆放方案。

和常见的「体积相除」估算不同，本工具使用的是二维回溯搜索（2D bin packing）排布算法： 会同时比较纸箱的正放与倒置两种朝向，在柜底平面上求解单层能摆下的最大箱数， 再结合柜内高度与托盘高度推算整柜层数，因此结果比简单估算更接近真实现场。 若货物打托出运，勾选「托盘」并填写托盘尺寸与每托箱数即可切换为托盘码盘模式，工具会按交错码盘计算每托层数与整托高度。

所有计算均在浏览器本地完成，货物数据不会上传到任何服务器，刷新页面即清除。页面依赖文件随站点一起加载，离线也可使用。

四步完成一次装柜计算

  1. 选择柜型　下拉选择 20GP / 40GP / 40HQ / 45HQ，或选「自定义」手动填写柜内长宽高与最大承重。
  2. 录入货物　填写纸箱长宽高、数量与单重；点「+ 添加」可录入多个 SKU，也可以用 Excel 模板批量导入。
  3. 按需勾选托盘　打托出运的货物勾选「托盘」，填写托盘长宽、托盘高与每托箱数，工具会自动按交错码盘排布。
  4. 计算并导出　点「开始计算」查看整柜数量、装载率与货物明细，中间区域是 3D 装柜预览，方案可导出为 Excel 或 PDF。

常见问题

装柜计算的结果是精确值吗？

不是。结果是理论最大值。实际装柜还会受货物承压能力、不规则外形、加固与缓冲材料、柜门尺寸和人工摆放方式影响。建议按计算结果预留 3%~5% 的余量，重货还需单独核对重量上限。

为什么算出来的箱数比「柜内容积 ÷ 单箱体积」少？

因为纸箱是刚体，靠墙和拐角一定会留下无法利用的空隙。本工具用二维回溯搜索在柜底平面上求解实际能摆下的箱数，再乘以可堆层数，因此比单纯的体积相除更接近真实装柜。

支持托盘装柜计算吗？

支持。勾选「托盘」后填写托盘长宽、托盘高与每托箱数，工具会以托盘为单位逐层码放，并给出每托层数、整托高度以及整柜可装托盘数，3D 预览中木色底座即为托盘。

货物数据会上传到服务器吗？

不会。所有计算都在浏览器本地完成，货物与柜型数据不会上传到任何服务器，关闭或刷新页面后即清除。

需要安装或注册吗？

不需要。打开网页即可使用，也不用登录。页面依赖文件随站点一起加载，断网状态下同样可以完成计算。
